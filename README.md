# bmstu-computer-modeling-lab3

Стохастическое моделирование надёжности системы управления летательным аппаратом с резервированием элементов методом Монте-Карло.

## Исследование сходимости метода Монте-Карло

### Цель эксперимента

Исследовать сходимость метода Монте-Карло при оценке вероятности безотказной работы системы управления летательным аппаратом с резервированием элементов.

Полученные результаты моделирования сравниваются с аналитическим расчётом надёжности системы.

### Параметры эксперимента

- Продолжительность моделирования: 5 часов.
- Количество испытаний: 100, 1 000, 10 000, 100 000 и 1 000 000.
- Интенсивность отказов датчиков: 0.0005 ч⁻¹.
- Интенсивность отказов вычислителей: 1/3000 ч⁻¹.
- Интенсивность отказов исполнительного механизма: 1/1500 ч⁻¹.

### Аналитический расчёт

Для системы с резервированием надёжность определяется выражением:

\[
R(t) = R*{\text{sensor}}(t) \cdot R*{\text{computer}}(t) \cdot R\_{\text{actuator}}(t)
\]

Аналитическое значение надёжности при продолжительности моделирования 5 часов:

\[
R\_{\text{аналит}} = 0.99666324
\]

### Результаты моделирования

Для каждого значения количества испытаний выполняется моделирование методом Монте-Карло.

Оценка надёжности определяется как отношение количества работоспособных систем к общему количеству испытаний:

\[
R*{\text{MC}} = \frac{N*{\text{success}}}{N}
\]

Абсолютная ошибка рассчитывается по формуле:

\[
Error = |R*{\text{MC}} - R*{\text{аналит}}|
\]

### Визуализация результатов

По результатам эксперимента построены два графика:

1. `results/convergence.png` — зависимость абсолютной ошибки от количества испытаний.
2. `results/reliability.png` — зависимость оценки надёжности от количества испытаний с отображением аналитического значения.

### Вывод

Эксперимент позволяет исследовать влияние количества испытаний на точность оценки надёжности методом Монте-Карло.

При увеличении количества испытаний оценка надёжности в среднем приближается к аналитическому значению. При этом из-за случайного характера моделирования абсолютная ошибка может изменяться немонотонно.
