## Описание

Разработана стохастическая модель надёжности упрощённой системы управления летательным аппаратом с резервированием элементов. Исследуется влияние резервирования датчиков и бортовых вычислителей на вероятность безотказной работы системы.

Для моделирования случайных отказов компонентов используется метод Монте-Карло. Полученные результаты сравниваются с аналитическими расчётами. Дополнительно исследуется сходимость метода Монте-Карло при увеличении количества испытаний.

## Математическая модель

### Структура системы

Рассматривается система управления летательным аппаратом, состоящая из следующих компонентов:

- Два датчика (Д1, Д2), работающих по параллельной схеме резервирования.
- Два бортовых вычислителя (В1, В2), работающих по параллельной схеме резервирования.
- Один исполнительный механизм (И1), являющийся обязательным элементом системы.

Система считается работоспособной, если хотя бы один датчик, хотя бы один вычислитель и исполнительный механизм остаются исправными.

Условие работоспособности:

$$
(Д_1 \lor Д_2)\land(В_1 \lor В_2)\land И_1
$$

### Исходные параметры

Для моделирования используются следующие параметры:

| Компонент | Среднее время безотказной работы, ч | Интенсивность отказов, ч⁻¹ |
|---|---:|---:|
| Датчик | 2000 | 0.0005 |
| Вычислитель | 3000 | 1/3000 |
| Исполнительный механизм | 1500 | 1/1500 |

Интенсивность отказов определяется через среднее время безотказной работы:

$$
\lambda = \frac{1}{MTTF}
$$

### Основные допущения

1. Все компоненты исправны в начальный момент времени.
2. Отказы компонентов являются случайными событиями.
3. Интенсивности отказов постоянны.
4. Отказы компонентов независимы.
5. После отказа компонент не восстанавливается.
6. Резервный элемент сразу принимает на себя выполнение функции отказавшего элемента.
7. Общие причины отказов не учитываются.

### Распределение времени до отказа

Время до отказа каждого компонента моделируется экспоненциальным распределением:

$$
T_i \sim Exp(\lambda_i)
$$

Генерация случайного времени до отказа выполняется с использованием функции `numpy.random.exponential()`.

## Аналитический расчёт надёжности

### Надёжность отдельного компонента

Для компонента с постоянной интенсивностью отказов вероятность безотказной работы определяется выражением:

$$
R_i(t)=e^{-\lambda_i t}
$$

### Надёжность резервированной пары

Для двух одинаковых независимых компонентов, работающих по параллельной схеме, достаточно исправности хотя бы одного элемента:

$$
R_{\text{рез}}(t)=1-(1-R_i(t))^2
$$

### Надёжность системы с резервированием

Общая надёжность системы определяется произведением надёжностей двух резервированных подсистем и исполнительного механизма:

$$
R_{\text{сист}}(t)=
R_{\text{датчики}}(t)\cdot
R_{\text{вычислители}}(t)\cdot
R_{\text{исполнительный механизм}}(t)
$$

После подстановки исходных выражений:

$$
R_{\text{сист}}(t)=
[1-(1-e^{-\lambda_d t})^2]
[1-(1-e^{-\lambda_v t})^2]
e^{-\lambda_i t}
$$

При продолжительности моделирования 5 часов аналитическое значение надёжности составляет:

$$
R_{\text{аналит}}(5)\approx 0.99666324
$$

## Моделирование методом Монте-Карло

Для оценки надёжности системы реализовано моделирование методом Монте-Карло.

В каждом испытании генерируются случайные времена до отказа всех компонентов. Затем проверяется условие работоспособности всей системы.

Оценка надёжности определяется как отношение количества работоспособных систем к общему количеству испытаний:

$$
R_{\text{MC}}=\frac{N_{\text{success}}}{N}
$$

где:

- \(N_{\text{success}}\) — количество успешных испытаний;
- \(N\) — общее количество испытаний.

## Исследование сходимости метода Монте-Карло

### Цель эксперимента

Исследовать зависимость точности оценки надёжности от количества испытаний метода Монте-Карло.

### Параметры эксперимента

- Продолжительность моделирования: 5 часов.
- Количество испытаний: 100, 1 000, 10 000, 100 000 и 1 000 000.
- Аналитическое значение надёжности: 0.99666324.

### Методика исследования

Для каждого значения количества испытаний проводится отдельное моделирование системы.

Абсолютная ошибка определяется как:

$$
Error=|R_{\text{MC}}-R_{\text{аналит}}|
$$

Полученные значения используются для оценки сходимости метода Монте-Карло к аналитическому результату.

### Визуализация результатов

По результатам эксперимента построены два графика:

1. `results/convergence.png` — зависимость абсолютной ошибки от количества испытаний.
2. `results/reliability.png` — зависимость оценки надёжности от количества испытаний с отображением аналитического значения.

### Вывод

При увеличении количества испытаний оценка надёжности в среднем приближается к аналитическому значению. Абсолютная ошибка может изменяться немонотонно вследствие случайного характера моделирования.

## Сравнение систем с резервированием и без него

### Цель эксперимента

Исследовать влияние резервирования датчиков и бортовых вычислителей на вероятность безотказной работы системы управления летательным аппаратом.

### Исследуемые конфигурации

Рассматриваются две конфигурации системы:

1. **Без резервирования:** один датчик, один вычислитель и один исполнительный механизм.
2. **С резервированием:** два датчика и два вычислителя, работающих по параллельной схеме, и один исполнительный механизм.

### Аналитическая модель системы без резервирования

Для системы, в которой все три компонента являются обязательными, надёжность определяется выражением:

$$
R_{\text{без рез}}(t)=
e^{-(\lambda_d+\lambda_v+\lambda_i)t}
$$

### Параметры эксперимента

- Время эксплуатации: от 0 до 1000 часов.
- Шаг изменения времени для аналитического графика: 10 часов.
- Количество испытаний Монте-Карло: 100 000 для каждой временной точки.
- Временные точки численного сравнения: 5, 100, 250, 500, 750 и 1000 часов.

### Методика исследования

Для каждой конфигурации рассчитывается аналитическая вероятность безотказной работы. Затем проводится моделирование методом Монте-Карло для выбранных временных точек.

Экспериментальные результаты сравниваются с аналитическими значениями.

### Результаты

При времени эксплуатации 1000 часов аналитическая надёжность составляет:

- Без резервирования: 0.223130.
- С резервированием: 0.309963.

Разница между значениями:

$$
\Delta R=0.309963-0.223130
$$

$$
\Delta R\approx 0.086833
$$

Таким образом, резервирование повышает вероятность безотказной работы примерно на 8.68 процентного пункта при времени эксплуатации 1000 часов.

### Визуализация результатов

По результатам эксперимента построены два дополнительных графика:

1. `results/redundancy_comparison.png` — аналитическое сравнение надёжности двух конфигураций в зависимости от времени эксплуатации.
2. `results/monte_carlo_comparison.png` — сравнение аналитических расчётов и результатов моделирования методом Монте-Карло для обеих конфигураций.

### Вывод

Резервированная конфигурация обладает более высокой надёжностью на всех исследованных временных интервалах. Результаты моделирования методом Монте-Карло согласуются с аналитическими расчётами.

Проведённый эксперимент подтверждает положительное влияние резервирования датчиков и вычислителей на надёжность системы управления летательным аппаратом.
